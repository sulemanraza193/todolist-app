# 📝 Todo List App

A simple and responsive Todo List application built with JavaScript, HTML, and CSS.  
This app allows users to add, complete, and delete tasks with data stored in Local Storage so tasks remain saved even after refreshing the page.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Persistent data after page refresh
- 📱 Responsive and clean UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Local Storage API

---

project-folder/

---

## ⚙️ How It Works

### Add Task
Users can enter a task in the input field and click the **Add Task** button.

### Complete Task
Clicking on a task marks it as completed.

### Delete Task
Users can remove tasks by clicking the **Delete** button.

### Local Storage
All tasks are automatically saved in the browser using Local Storage.
